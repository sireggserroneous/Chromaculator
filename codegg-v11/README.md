## Run it

```bash
cd codegg-v11 && cargo build --release        # std only, offline
cargo test --release                          # 15 tests incl. the pipeline law
cargo clippy --all-targets -- -D warnings     # the mandate, clean
target/release/eggv11 transmute <file>        # .egg11; filters+arms auto
target/release/eggv11 restore <f>.egg11       # conservation-gated (.egg10/.egg9/.egg8 too)
target/release/eggv11 audit [--full]          # per-tier geometry proofs
target/release/eggv11 gen-prior <site files>  # regenerate src/prior_tab.rs (deterministic)
node tools/drills.js                          # the 75-drill battery
node tools/ledger11.js                        # the milestone ledger vs v10, in lanes
node tools/standings.js corpus-real/*         # the home tournament
node tools/challengers.js <files>             # the armored rivals
node tools/countersign-big.js                 # certutil fingerprints, big arena
```
