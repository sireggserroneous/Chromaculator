A = 2ᵉ · Q · B + R · exact at every width

Wub ÷

Division will not fit a grid the way multiplication does, and most quotients do not terminate at all. Both problems go away by refusing to round: run the division only as far as the grid allows and keep what is left over, so A = 2e·Q·B + R holds exactly at every width. Q is an ordinary stalk inside (−1,1), so it draws like any other number. e is the multiplier on the boundary — the shift that brings the quotient back inside, normalised so the leading cell is never wasted. R is a stalk too, and it is what the repeating digits would have been. The grid drawn is the tableau: the rows of B that got subtracted, which is the same rectangle Wub × draws — only solved for rather than read off. Fold is the equator, Inner reaches north, Outer south. Mantissas carry down the rack and exponents add, so the running ring is where the answer actually sits; colour comes from the mantissa, radius from the ring. Push leaves the tableau alone and answers beside it: the quotient Q spelled with as many lit cells as it has, which is its address. Push conserves the value, so nothing else moves — that is the point of it. The phasors sit 180° apart and sum tip to tail. The faint green dot on each arm is R — the part that did not fit. Widen the grid and watch it fall back toward the arm it came from.
