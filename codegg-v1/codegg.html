The error spells its own address

The square is a number: cell i weighs 2^(L-1-i), so every cell has a distinct magnitude. Damage of size d at cell i moves the value by exactly d·2^(L-1-i) — one quantity that names the cell, the direction and the size at once. Keep the value mod two small primes, and that difference is the diagnosis: drawn in the site's own colours, the syndrome is a single lit cell sitting exactly where the wound is.

The product code next door needs 4N−1 sums to triangulate a position. Here two residues — about three bytes for a 128-byte square — do it alone, because position was encoded in place value all along. And since push conserves the value, the check survives respelling: press Push below and watch every colour move while both residues stand still.

The arithmetic

—

A magnitude-2 error — a cell crossing from −1 to +1 — spells itself one place to the left, because 2·2^w = 2^(w+1): the syndrome square lights the neighbouring cell and says so. This is a residue code in the arithmetic-codes lineage (Avizienis 1971 — the same Avizienis whose 1961 signed digits the digits page already credits). Its honest costs, measured in tools/codegg.test.js: a silent floor of about 1/(p·q), and a multi-error syndrome can imitate a smaller one. The product code has neither failure mode; it pays five times the redundancy to be that sure.
