base(chroma‑utf)

A string is a number written with Chroma UTF digits. Each character is one digit in base 4096 — ten bits of code padded to twelve, which is three whole nibbles, so a character never straddles a nibble and four cells wide it is exactly three rows. The integer and the picture are the same object: the number is the polynomial the bodies draw. One card per line, commas between the items on a card, the way Wub ± holds a rack.
