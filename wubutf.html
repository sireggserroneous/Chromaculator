Sorting by sound, drawn

Every character is a Chroma UTF code in ring 9, so every code is ten bits in the same four by four frame. A word is a row of those squares, and the order is legible in the pictures: the first square where two names differ holds the cell that decides which comes first. Push stops collapsing a name to one reading and lists every one it has, each at its own position — with the positional rules on, or off, which is the difference between cervezas having no /k/ reading and having kervezas. The fold is outlined. Ten bits pad to three whole nibbles and twelve bits lay into a four by four square, so four cells stay empty in every frame — which is exactly why the frames line up and a row reads as a row.
