Sorting by sound, drawn

Every character is a Chroma UTF code in ring 9, so every code is ten bits in the same four by four frame. A word is a row of those squares, and the order is legible in the pictures: the first square where two names differ holds the cell that decides which comes first. The fold is outlined. Ten bits pad to three whole nibbles and twelve bits lay into a four by four square, so four cells stay empty in every frame — which is exactly why the frames line up and a row reads as a row.
